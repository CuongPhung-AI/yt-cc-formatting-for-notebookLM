Direct YouTube URL Fetching

To fetch subtitles directly from YouTube URLs, run the local Python backend helper:

python format_subtitles.py --serve

This runs the Web UI with full yt-dlp integration at http://localhost:8000.

💡 Offline / Static Mode: You can also copy/paste transcript text or drag & drop .srt, .vtt, .sbv, or .txt files directly into the editor below right now without needing a server!
